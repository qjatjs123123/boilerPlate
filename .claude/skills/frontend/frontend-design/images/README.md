# 참고 스크린샷 — 화면 디자인 기준

`frontend-design` 스킬이 실행될 때 이 폴더의 이미지를 **반드시 먼저 열어 보고** 화면 모양의 기준으로 삼는다.
이미지가 없으면 스킬 본문의 원칙만으로 진행한다.

## 넣는 법

- 형식: PNG 또는 JPG, **3~6장** (너무 많으면 매번 읽는 데 부담이 커진다)
- 파일명: 화면 종류를 한글로 — 예: `목록조회.png`, `입력폼.png`
- 종류를 다양하게: 목록(표), 입력 폼, 상세 화면, 대시보드, 모달, 토스트 등
- ⚠️ **회사명·로고·고객사명·금액·개인정보·내부 메일 주소 등 민감 정보는 가리고** 넣는다 — 이 폴더는 git 에 커밋된다.
- 이미지를 넣으면 아래 표에 한 줄씩 추가한다.
