# vibe-setup — 개발 환경 준비

사용자는 비개발자다. 진행 상황을 짧고 쉬운 말로 알린다.

## 절차

1. `make doctor` 실행.
   - 실패하면 출력에 나온 "없음" 항목을 **설치 방법과 함께 그대로** 안내하고 멈춘다. 도구 설치는 사용자가 직접 해야 한다(sudo·GUI 설치 등).
   - Docker가 꺼져 있다는 메시지면 "Docker Desktop을 켜 주세요"라고 안내하고 멈춘다.
2. `make setup` 실행 (수 분 걸릴 수 있음을 먼저 알린다).
   - 실패하면 에러를 읽고 원인을 한 줄로 설명한다. 포트 충돌(5432 사용 중)이면 "DB가 쓰는 번호(5432)를 이미 다른 프로그램이 쓰고 있어 5433으로 바꿔도 될까요?"처럼 묻고, 확인을 받으면 `make db-port PORT=5433` 후 `make setup` 을 다시 실행한다 (`.env` 를 직접 열거나 고치지 않는다 — 읽기가 차단돼 있다).
   - `make setup` 은 `main`(배포용)·`dev`(개발 기준) 브랜치도 만들고 dev 로 옮겨 둔다. 이후 코드를 바꾸는 작업은 모두 dev 에서 작업 브랜치를 만들어 한다 (`.claude/skills/COMMON.md` §3-B).
3. 성공하면 "준비가 끝났습니다. 이제 만들고 싶은 기능을 말씀해 주세요."로 마무리하고, 원래 요청이 있었다면 이어서 처리한다.

## 금지
- `.env`/`.env.local` 내용을 읽거나 출력하지 않는다 (예시 파일 `.env.example`만 참고).
- 시스템 패키지 설치(sudo) 명령을 직접 실행하지 않는다.
