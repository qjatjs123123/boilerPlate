# DOMAIN-MAP — 이 서비스에 있는 "것들"과 저장 위치

새 데이터를 설계하기 **전에** 이 표부터 본다 (`db-design` 스킬 0단계). 새 요청에 나온 명사는 먼저 아래 개념 중 하나에 매핑하고, 어디에도 안 맞을 때만 새 테이블을 만든다.

- 갱신 시점: spec-run models Task 에서 `backend/data-model.yaml` 을 바꿀 때 같이 고친다. 세션 시작 훅이 「개념」·「저장 위치」 열을 요약해 매번 보여준다.
- 정확한 컬럼·타입은 `backend/data-model.yaml`, 그림은 `docs/backend/ERD.md`(자동 생성).
- 행 형식을 바꾸지 않는다 — 훅이 표의 1·3열을 읽는다.
